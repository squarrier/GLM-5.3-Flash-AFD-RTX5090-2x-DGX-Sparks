# V4.0 lab release boundaries

This release contains source and portable wrappers, not model weights or built CUDA assets. It is provided as-is for lab use. The public packaging was CPU-checked; it is not a separately device-qualified deployment. The original selected-0.50 lifecycle check failed and later clean closure does not establish restart or unattended recovery. There is no production, quality, or comparative-speed claim.

See [source provenance](SOURCE-PROVENANCE.md) for the inherited-source evidence and its limits, and [build notes](BUILD.md) for tested-versus-published source identity.
